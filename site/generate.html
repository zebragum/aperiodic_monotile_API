Patch generation, editable N-gon instances, edge styles, collections, and materials in one video. The same API powers the desktop app and other add-ons.

  • Surfaces without obvious repetition Ordered variation for floors, facades, panels, sculpture, and procedural environments without a wallpaper repeat unit giving the game away on camera.
  • Flat by default Picture and vector exports stay planar. Raise thickness only when you want 3D extrusion.
  • Images, vectors, meshes Free JPG/PNG previews. Paid SVG, CSV, JSON, STL, GLB, and related packs.
  • Flexible boundaries Rectangles, circles, triangles, hexagons, rounded rects — tune tile scale and generate.

Install

Desktop app, or Blender, or call the API.

  • Windows app Download AperiodicGenerator.exe, paste your API key, pick formats, Generate.
  • Blender Install the ZIP in Preferences → Add-ons, enable Untiling, open the Monotile sidebar.
  • Inkscape Copy the extension files into Inkscape’s extensions folder and restart.
  • API POST /v1/patch — see docs.
