This product builds on newly discovered Spectre / Tile(1,1) mathematics.

The API packages aperiodic monotile geometry for practical workflows. The mathematical discovery and reference tooling should be credited clearly.

Mathematical provenance

Tile(1,1), also known as Spectre.

Tilings are based on Tile(1,1) / Spectre theory as presented by David Smith, Joseph Samuel Myers, Craig S. Kaplan, and Chaim Goodman-Strauss in A chiral aperiodic monotile.

Reference implementation lineage

Substitution and placement logic follows public tooling.

The substitution rules and affine placement logic used by the API follow publicly shared Spectre tooling, including Craig S. Kaplan's Spectre explorer and community ports such as shrx/spectre.
