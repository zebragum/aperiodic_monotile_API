Explore real API outputs without spending compute.

This demo uses pre-generated examples, so it is cheap enough to show publicly. The production API can generate fresh custom geometry for authenticated users.

View-only previews are not a security boundary. The edge-style menu is illustrative: real curvy/spiky silhouette sculpting lands on /v1/capabilities.roadmap milestones; STL output remains solid unless explicit outline meshes ship later. API documentation

One request creates a clipped geometry patch.

Send a JSON mask, choose a retention policy, and request the formats your pipeline needs. Jobs return signed URLs for completed artifacts. 

{
  "scale": 1,
  "mask": {"type": "triangle", "center": [0, 0], "side_length": 50},
  "retention": "clip",
  "formats": ["svg", "json"],
  "svg_pixel_target": 500,
  "svg_margin": 0,
  "svg_compact": true
}
