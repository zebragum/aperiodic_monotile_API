Interactive view-only demo

Explore real API outputs without spending compute.

This demo uses pre-generated examples, so it is cheap enough to show publicly. The production API can generate fresh custom geometry for authenticated users.

View-only previews are not a security boundary. Each bundled example fixes its mask geometry and tessellation snapshot; in production you regenerate with parameter changes (aspect ratio, mask size, tessellation depth, scale, retention, formats). Edge styling controls here only dress the SVG preview; STL meshes stay volumetric slabs with solid facets. Paid tiers unlock downloadable artifacts and higher limits for production runs.

API documentation

One request creates a clipped geometry patch.

Send a JSON mask, choose a retention policy, and request the formats your pipeline needs. Jobs return signed URLs for completed artifacts. 

{
  "scale": 1,
  "mask": {"type": "triangle", "center": [0, 0], "side_length": 50},
  "retention": "clip",
  "formats": ["svg", "json"],
  "svg_pixel_target": 500,
  "svg_margin": 0,
  "svg_compact": true
}
