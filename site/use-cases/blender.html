Blender workflow

Spectre monotile geometry for Blender.

Generate aperiodic tilings as SVG, JSON, CSV, STL, or glTF-ready data for Blender panels, instanced meshes, procedural scenes, and architectural visualization.

Why it matters

Aperiodic monotile layouts create non-repeating structure without random noise. That is ideal for surfaces, screens, floors, facades, sculptures, and generative environments.

Current demo

The repository includes a starter Blender add-on that requests an SVG patch from the live API and imports it when Blender's SVG importer is available.

Paid plugin path

The commercial plugin should add API-key storage, glTF/JSON instancing, material controls, progress UI, and larger paid-tier limits.

API example

Request a triangle or circle and import the geometry.

Blender users can start with SVG curves, then move to instanced mesh workflows as the plugin matures.

{"mask":{"type":"circle","center":[0,0],"radius":50},"formats":["svg","json"],"retention":"clip"}
