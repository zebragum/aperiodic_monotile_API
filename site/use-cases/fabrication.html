Fabrication

Raw Spectre tiling geometry for making real things.

Clip Spectre tiling patches onto laser-ready panels, CNC beds, molds, engraving paths, decorative screens, inlays, and packaging—all from the same parameterized API.

SVG-first output

Compact SVG output keeps vector workflows friendly for Illustrator, Inkscape, LightBurn, laser software, and downstream geometry cleanup.

Controlled masks

Request exact circles, rectangles, squares, triangles, rounded rectangles, or hexagons with centroid, intersection, or clip retention.

Stable IDs

Every retained tile receives a deterministic ID, making it easier to map colors, materials, cuts, labels, or assembly metadata.

Production detail

Clip to the mask when empty space is unacceptable.

The API keeps all polygonal pieces from clipping operations so fabrication previews do not drop multipart edge geometry.
