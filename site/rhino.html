Rhino

Fetch a patch. Draw the curves.

Same generation options as Inkscape and Blender: side styles, coloring, tile scale, mask shapes. Run interactively in Rhino or call from Grasshopper.

Download Rhino script Get a key
  • Interactive, prompts for format, mask, tile size, side style, and coloring.
  • Imports curves, places closed tile outlines on a Monotile layer (from instance JSON).
  • Side styles, flat, curvy, wavy, jagged, blocky.
  • Coloring, greyscale, each random, mystics (Gamma), rainbow by type (SVG / PNG / JPG).
  • Depth, defaults to 0 for STL/GLB; extrude in Rhino when you want thickness.
