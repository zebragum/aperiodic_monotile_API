WHAT YOU BOUGHT
---------------
This kit is for Blender artists who want large aperiodic monotile surfaces that
do NOT read like obvious CG tiling. You get:

  1. aperiodic_monotile_generator_blender.zip  — install in Blender 4.2+ (includes blender_manifest.toml)
  2. samples/                                   — example SVG, PNG, GLB, CSV, JSON
  3. This guide

You still need an API key from the hosted generator (see below). The add-on
calls the live API to build geometry; it does not run offline.


WHY THIS EXISTS (30 seconds)
---------------------------
Regular grids repeat. Your eye catches the unit tile in camera, motion, and
lighting. Aperiodic monotile patches stay ordered but avoid that wallpaper
beat — surfaces look more natural on floors, facades, and environments.


STEP 1 — GET AN API KEY
-----------------------
Open:  https://aperiodicgenerator.com/docs.html#access

  • Free tier: small PNG/JPG previews only (good for testing the add-on flow)
  • Solo plan ($10/mo or $79 lifetime): production exports including GLB, up to 40,000 tiles per job
  • Pro plan ($99/mo or $999 lifetime): studio license, up to 400,000 tiles per job

If you received a discount code in your Gumroad receipt email, apply it at checkout
on the site.


STEP 2 — INSTALL THE ADD-ON
---------------------------
1. In Blender: Edit → Preferences → Add-ons → Install…
2. Select: aperiodic_monotile_generator_blender.zip
3. Enable: "Aperiodic Monotile Generator"
4. Press N in the 3D View → sidebar tab "Monotile"


STEP 3 — FIRST SCENE
--------------------
1. Paste your API key in the Monotile panel
2. Choose boundary (circle, rectangle, hexagon, etc.)
3. Set tile scale and extrusion depth
4. Click "Generate and Import GLB"
5. Wait for the job to finish (Blender may pause while polling)

Imported tiles land in a collection named Monotile <job_id>.
