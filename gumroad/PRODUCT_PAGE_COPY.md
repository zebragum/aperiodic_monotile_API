## Stop obvious tile repetition in Blender

Regular floor and facade grids look fine in stills — then the camera moves, light grazes the surface, and the repeat unit gives the game away. **Aperiodic monotile** geometry breaks that spatial beat: the layout stays coherent, but it does **not** collapse to one wallpaper cell. The result reads more natural in environments, archviz, and procedural scenes.

This kit connects **Blender 4.0+** to the hosted **Aperiodic Monotile Generator API** so you can generate a **GLB patch** (one movable node per tile) and import it in one click.

### Workflow (60 seconds)

1. Install the add-on from the ZIP  
2. Get an API key at **aperiodicgenerator.com** (free tier = raster tests; **Solo** = GLB production)  
3. Choose mask → **Generate and Import GLB**  
4. Shade, instance, or edit per tile in Blender  

Internet required — geometry is generated on the hosted API, not offline.
